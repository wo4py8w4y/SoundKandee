Blow-by-Blow Architecture & Choice Reasonings

Audio-visual Android apps sit on top of awkward hardware/OS boundaries: Skia software offscreen bitmaps refuse RuntimeShaders, Android's Visualizer API emits unsigned 8-bit bytes instead of PCM-16, and StateFlow drops transient beats under UI pressure. Below is every unusual path taken in SoundKandee—and why it exists.

Oddity 1 — Split-Pipeline Guard Against Skia's RuntimeShader Software Crash

The Trap: Jetpack Compose's offscreen Canvas(ImageBitmap(...)) used for Feedback Echo Trails is always software-backed in Android's Canvas pipeline. Attempting to draw an AGSL RuntimeShader (Nebula Plasma) directly into that offscreen canvas throws IllegalArgumentException: Software rendering doesn't support RuntimeShader.

Why We Took This Path: Rather than banning Feedback Echo Trails whenever shaders are active, LayerRenderers.drawNebulaFluid checks drawContext.canvas.nativeCanvas.isHardwareAccelerated at draw time and swaps to multi-lobe radial gradient clouds when targeting software bitmaps or API 24–32 devices. Meanwhile, all 13+ spatial MilkDrop post-FX shaders execute outside the echo buffer inside the hardware-accelerated outer Modifier.graphicsLayer { renderEffect = ... } stage.

Oddity 2 — Codename Archeology: ChromaWave Identifiers Inside SoundKandee

The Quirk: Every user-facing string, launcher asset, and microsite surface says SoundKandee, yet internal Kotlin symbols (ChromaWaveViewModel, ChromaWaveScreen), applicationId = "com.aistudio.chromawave.vzxqkm", namespace = "com.example", and DataStore file "chromawave_prefs" retain the original codename.

Reasoning: Mutating applicationId or DataStore preference names after initial installation breaks Android package upgrade continuity and silently wipes saved user presets. Keeping internal symbols decoupled preserved every existing workspace while rebranding the public identity cleanly.

ConfigurableDspProcessor.kt • processPcm16() vs processVisualizerBytes()

Oddity 3 — Two Asymmetrical Front-End Ingestion Math Paths in One DSP Engine

The Quirk: Unlike single-format desktop audio engines, ConfigurableDspProcessor implements two separate ingestion pipelines converging on buildAudioFrame().

Reasoning: AudioRecord and Android 10+ MediaProjection capture emit standard signed 16-bit PCM (ShortArray) requiring user-selectable windowing and a Radix-2 Cooley-Tukey 1024-FFT. Android's Session-0 Visualizer API instead delivers unsigned 8-bit bytes biased around 128 and pre-computed interleaved re/im FFT bytes. Unifying both outputs into identical 64-band log arrays ensures presets never drift when switching audio inputs.

PlaybackCaptureBridge.kt • AudioCaptureCoordinator.kt

Oddity 4 — Global Singleton Bridge + Synchronous Beat Forwarding vs. StateFlow

The Quirk: Cross-component audio uses mutable callbacks on PlaybackCaptureBridge and invokes tempoSyncEngine.onAutoBeatDetected(timestampMs) synchronously inside handleRealAudioFrame rather than collecting audioFrame flow in the ViewModel.

Reasoning: StateFlow is conflated by design—a brief UI frame stall causes newer quiet frames to overwrite a preceding beatOnset = true frame before collectors wake up, starving BPM estimation. Synchronous audio-thread delivery guarantees zero dropped beats with zero Binder IPC overhead inside the same process.

Oddity 5 — Zero-Recomposition 60fps Render Loop & Manual Test Clocks

The Quirk: Parameter evaluation runs inside a withFrameNanos loop updating Compose states read solely inside Canvas { ... }, while HUD TempoSyncSnapshot updates are throttled every 3rd frame (~20 Hz) and Compose tests set mainClock.autoAdvance = false.

Reasoning: Pushing 60Hz mutations into the top-level VisualizerUiState triggers full Dock slider/switch recompositions every 16ms. Isolating reads to DrawScope keeps the Compose tree idle while maintaining locked 60fps shader smoothness—requiring explicit clock stepping in Robolectric UI tests because continuous withFrameNanos prevents infinite-wait idling.

AgslShaders.kt • COMPOSITE_FX_SRC • FEEDBACK_WARP_SRC

Oddity 6 — Fused Single-Pass AGSL Uber-Shader vs. Chained RenderEffects

The Quirk: MilkDrop liquid warp, zoomexp tunnel pull, anamorphic stretch, pinwheel twist, wavefold, vortex, ripple, chromatic split, CRT scanlines, solarize, posterize, mirror-quad, and polar unwrap are compiled into one composite AGSL script.

Reasoning: Chaining 10+ separate RenderEffect passes saturates mobile GPU memory bandwidth. Combining coordinate transformations into a single UV warp followed by minimal multi-tap color operations allows multiple MilkDrop transformers to run simultaneously at 60fps.

PreferencesRepository.kt • app/build.gradle.kts

Oddity 7 — Hand-Rolled org.json Persistence (Room, Moshi & Firebase Commented Out)

The Quirk: Despite commented-out Room/Moshi/Firebase blocks in Gradle, all preset serialization uses manual JSONObject / JSONArray marshalling inside Jetpack DataStore.

Reasoning: Cloud sync was intentionally omitted to preserve 100% offline privacy, and avoiding KSP/reflection serialization shrinks APK size and speeds up FOSS builds. Defensive opt* decoding also migrates older presets seamlessly when new LFO/Tempo fields appear.

SyntheticMusicGenerator.kt • AudioCaptureCoordinator.kt

Oddity 8 — Synthetic Idle Music Feeding Real 1024-FFT DSP Instead of Mock Curves

The Quirk: Idle synthesis generates real 44.1 kHz PCM-16 kick drums, sub-bass, pentatonic arps, and noise hi-hats and feeds them into an actual ConfigurableDspProcessor instance.

Reasoning: Fake UI arrays bypass windowing, noise-floor gates, spectral centroid pitch tracking, bandpass filter windows, and auto-beat PLL confidence. Synthesizing authentic PCM-16 makes idle mode behave identically to real playback and hands off cleanly the instant lastRealSignalMs detects live audio.

DeviceTapDetector.kt • processSample()

Oddity 9 — Permissionless Tap Gesture with 4-Sample Gravity IIR Warmup

The Quirk: Falls back automatically from TYPE_LINEAR_ACCELERATION to raw TYPE_ACCELEROMETER with an alpha = 0.8f high-pass filter that suppresses the first 4 sensor events.

Reasoning: Without the 4-sample warmup gate, the uninitialized 9.81 m/s² static Earth gravity vector looks like an instantaneous impulse shock on startup, falsely randomizing presets on first screen open.

ScopedParam.kt • TempoSyncEngine.kt

Oddity 10 — Forward-Only Beat Snapping & Inversion-Safe Range Bounds

The Quirk: TempoSyncEngine.recordTap() snaps beat phase forward to floor(totalBeats) + 1.0, auto-PLL only nudges forward, and ScopedParam exposes computed orderedMin/orderedMax properties.

Reasoning: Backward beat jumps cause continuous visual oscillators and spirals to violently twitch backward during a live set. Computed min/max bounds let users drag dual-thumb sliders past each other without validation crashes.
